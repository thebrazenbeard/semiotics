# Roadmap

## R0 — foundation kernel

Maintain a tiny deterministic registry/query engine with explicit context, source provenance, multiple readings, claim state, tests, schema, and CI.

## R1 — evidence-bearing sign-event ledger

Add occurrence-level records with time/interval, producer/observer/interpreter roles, exact evidence references, source representation/digest rules, and correction/supersession history.

## R2 — curated comparative corpus

Build a small source-bound corpus spanning linguistic, visual, conventional, causal/indexical, iconic, behavioral, and multimodal cases. Include contradiction, historical drift, cross-cultural variation, and unresolved cases.

## R3 — discriminating evaluator

Build negative controls and intervention-style tests separating contextual compatibility from reference, communicative function, or producer intention.

## R4 — learned interpretation experiments

Only after R2/R3, compare learned semiotic representations against strong simple baselines.

## R5 — portfolio interoperability

Add narrow adapters only where consumers justify them: candidate exports toward Semantic Atlas, benchmarks for SPM, and conservation/non-equivalence cases for UNVTRSLR. Discovery evaluates any proposed shared abstraction.
