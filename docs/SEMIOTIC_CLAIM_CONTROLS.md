# Semiotic Claim Controls

Semiotic systems are vulnerable to overclaiming because a plausible interpretation can be mistaken for demonstrated meaning.

Prefer the weakest claim supported by evidence:

`REGISTERED_READING -> CONTEXT_COMPATIBLE_READING -> SUPPORTED_WITHIN_DECLARED_SCOPE -> SURVIVES_DISCRIMINATING_TESTS -> ADJUDICATED_BY_EXTERNAL_AUTHORITY`

The reference kernel mechanically establishes only the first two. A stored `supported` state remains supplied metadata.

Keep separate sign vehicle vs referent hypothesis; source attribution vs truth; context compatibility vs causal explanation; receiver interpretation vs producer intention; convention vs causal/indexical connection; support score vs calibrated probability; theory tag vs ontology truth; and semantic understanding vs permission or execution.

A discovered operational regularity may be real while its human-readable semantic label is wrong. Post-hoc interpretations should remain exploratory until a new test distinguishes them from serious rivals.

Peircean, Saussurean, pragmatic, structural, cognitive, biosemiotic, social-semiotic, and other frameworks may partition the same phenomenon differently. v0.1 therefore uses namespaced tags rather than one master taxonomy.

No finite registry or benchmark is summarized as recovering `THE_TRUE_MEANING` merely because one interpretation wins within a bounded test.
